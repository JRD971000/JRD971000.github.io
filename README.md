# Ali Taghibakhshi Website

This is a static website. It has no build step and can run directly on GitHub Pages.

## Local Preview

Open `index.html` in a browser, or run a lightweight local server from this folder:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## GitHub Pages

Use the contents of this folder as the root of the `JRD971000.github.io` repository. The `index.html`, `styles.css`, `assets/`, and `resume/` paths are already arranged for GitHub Pages.
